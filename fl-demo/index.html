Model compression

        
Real int8 quantization, magnitude pruning, and teacher-to-student distillation, each re-evaluated on the held-out validation set. Not modeled numbers.

        
        

          Adapter fine-tuning
          

            
            
            
            
          

        

        
LoRA freezes the base weights and trains a low-rank update, so only a fraction of the parameters move. QLoRA quantizes the frozen base to int8 first and keeps the adapters in fp32. Adapters are merged into the weights on save, so there is no inference cost. Fine-tune on a different cohort to see real adaptation.

On-device personalization

              never uploaded
            

            
The global model is shared by everyone. A small private adapter trained only on this device's own history is kept locally and never sent anywhere, not even clipped and noised. It is the one part of the system with no privacy cost, because nothing leaves.

How this ad got placed

            

          


          

            

              
Ad auction

              —
            

            

            
Ranked by eCPM = bid x predicted engagement x 1000. Each candidate's pCTR is a real forward pass through the deployed model with that advertiser's ad-side features. Second-price clearing: the winner pays the minimum that would still have won, never its own bid.

            no impressions yet
            
          

        

        

          What an advertiser is allowed to learn. Three protections, applied in order:
          delayed so a report cannot be correlated with the moment of a tap,
          crowd-anonymity thresholded so a bucket is only released once enough
          distinct devices share it, and aggregated so no row ever describes one person.
